tn_districts.geojson: the 37 Tamil Nadu features of the user-supplied file India_District_Boundary.json
(provided by Srikanth on 2026-10-06; fields DISTRICT_L / District / STATE). Coordinates rounded to 4 decimals,
names normalised to the spelling used in the alerts (e.g. TENI -> Theni, TUTICORIN -> Thoothukudi,
RANIPPETTAI -> Ranipet). Mayiladuthurai is not a separate district in this file (it lies inside Nagapattinam).
Used only to decide which district a patch of radar echo lies in; the outlines are never drawn or published.
